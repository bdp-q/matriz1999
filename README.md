# 🧑‍💻 WELCOME TO ENTER THE MATRIZ 1999 🧑‍💻

This is a small prototype of a game written in C using Allegro. The game is a plataformer inspired by matrix and retrô games.
<img width="1366" height="768" alt="image" src="https://github.com/user-attachments/assets/96ca3630-399a-48d4-8a56-7b59fdbeae37" />

the objective is simple. You have a few minutes to get to the exit, or you will go back to being jailed in the matrix. You have no weapon other then your legs and your newly adquired dodging skills, pass through all stages before the time runs out!

## How to install
Allegro is a C library that makes creating games an easier task. To run the game you will need to install it.
In linux:
``` 
sudo apt install liballegro5-dev
```
Once you have allegro, things get easier, now you only need to run the makefile and start the game!
```
make
./matriz1999
```
Have fun!

## How to play 
- You can move using wasd or the arrow keys. 
- If you see a health icon you can stand in it and press E to heal yourself;
- There is a special ability if you press the down key.(spoiler, it envolves slowing down bullets 👀) Test it out!
